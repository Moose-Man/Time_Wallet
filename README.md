# Time Wallet

**Time Wallet** is an Android application designed to help users log, track, and manage how they spend their time. It’s a personal time management tool that lets users input time logs, view their history, and analyze their time usage over days and weeks — much like a financial wallet, but for your hours.

---

## Features

- Add, update, and delete time logs
- View a chronological history of time logs
- Modern **Jetpack Compose** UI
- Persistent storage using **Room Database**
- Reactive updates to the UI via **LiveData** and **ViewModel**
- Kotlin Coroutines support for asynchronous database operations
